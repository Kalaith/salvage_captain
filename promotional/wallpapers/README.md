## Visual continuity

SC-07 is a long, low, patched steel workboat with a raised forward bridge,
cyan windows, three vertically stacked amber aft engines, bolted machinery,
and an external belly cargo rail. Struts retract in flight. Amber work lamps
and cyan optics punctuate navy space and cool steel. Recovery work, resourceful
engineering, and the scale of the derelicts supply the drama.

The source references are the [game description](../../game_page.json),
[authored wrecks](../../assets/data/sites.json),
[equipment](../../assets/data/modules.json), and
[upgraded workboat capture](../../docs/verification/ui_port_upgraded.png).

## Validation

For each image, inspect composition, game-specific visual anchors, unwanted
text, and file dimensions. Record any limitations in its prompt file.
These standalone promotional assets do not modify the runtime or game UI;
game publishing and interaction tests are not applicable to this art-only pass.
